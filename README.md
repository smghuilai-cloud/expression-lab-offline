# 表达实验室 · 每日离线表达练习

这是一个根据沟通练习综合整理内容独立设计的手机优先离线网页小软件。参考图只提供手机使用方向，页面和训练入口不照搬。

## 已包含

- 14 天训练：阅读、脱稿复述、录音/计时、复盘、打卡
- 四种表达镜头：故事、事情、观点、对话
- 对话拆解：家庭、同事、客户等场景
- 边界工作台：我的课题、对方课题、共同课题和必须介入的事项
- 60 秒随机词挑战
- 本机保存打卡和练习记录
- 导出练习记录 JSON
- 支持安装成手机主屏幕上的 PWA；核心内容不依赖网络

## 在电脑上预览

在此文件夹启动一个静态服务器，例如：

```powershell
python -m http.server 8765
```

也可以双击文件夹里的 `启动手机预览.bat`。

然后打开：`http://127.0.0.1:8765/`

直接双击 `index.html` 也能使用文字、计时和打卡功能；但浏览器通常不会允许 `file://` 页面调用麦克风，也不会注册离线缓存。需要录音和“添加到主屏幕”时，使用本地服务器或 HTTPS 地址打开。

## 手机使用

### 直接离线使用

手机上不运行 `.bat`。请把上级目录中的 `表达实验室-手机离线包.zip` 传到手机，解压后打开其中的 `index.html`：

- Android：文件管理器解压，点击 `index.html`，选择 Chrome 或其他浏览器打开。
- iPhone：在“文件”中解压，长按 `index.html`，选择“共享”后用 Safari 打开；如果系统只显示预览，建议使用下面的首次安装方式。

这样打开后，文字练习、计时、打卡和本机记录不需要网络。录音可能被手机浏览器的本地文件权限限制。

### 安装成手机主屏幕应用

如果希望像小程序一样从手机桌面打开，并使用录音，第一次需要通过 HTTPS 地址打开；安装完成后，缓存的页面可以断网使用。普通的 `http://电脑局域网地址:8766/` 主要用于同 Wi-Fi 预览，不能保证手机浏览器允许安装或调用麦克风。

电脑端的 `启动手机预览.bat` 只负责启动预览服务器，不能直接在手机上运行。

如果只是想把它作为一个独立离线网页使用，也可以把整个文件夹复制到手机支持的本地文件管理器中打开；文字练习不受影响。
